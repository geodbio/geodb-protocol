geodb-protocol

This host serves the JSON Schemas of the geoDB Open Exploration Protocol at the URIs named in their own $id. The files are served from the commit they are versioned in; the repository is the source of truth.

Exploration chain-of-custody schemas, v0.1.0

  • assay.json
  • certificate.json
  • collar.json
  • interval.json
  • laboratory.json
  • qc-sample.json
  • survey.json

STAC extension xpl:, v0.1.0

  • schema.json — the exploration vocabulary listed in stac_extensions on geoDB STAC items.

Source, OpenAPI description and examples: github.com/geodbio/geodb-protocol. A version segment is permanent: a published schema URI is never repointed.
